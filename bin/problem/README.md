Set of files containing problems to solve by programs.
The fforum-1-19.obf, 20-39 and 40-59 file where publish on FForum (a magazin of the Fédération Française d'Othello) in the 1990s.
The fforum-60-79.obf file was a set a problem devised by Bruno Causse.
The full-15.obf full-20.obf full-25.obf full-30.odb each contain a set of 1000 problem at respectively 15 20 25 30 empties.
The small-20.obf small-25.obf small-30.obf are extract the previous files with only 30 problems.
All the files contain the list of all the available moves of each position with their exact solved score. They are both usefull to test the performance of an othello engine, but also to debug them.
